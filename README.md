# ENJIMO Translate

> 不打断，不跳转。看到哪里，就在那里把词弄懂。

## 我为什么做它

看番看到一句没懂，暂停，退出全屏，打开翻译网站，粘贴，再切回来——等这一套动作做完，刚才的情绪也差不多散了。

上课也一样。老师讲到一个陌生词，我只想花几秒确认它是什么意思，而不是隆重地打开一个翻译软件，顺便被窗口、登录和各种按钮带走注意力。

所以有了 ENJIMO Translate。

它不想成为另一个功能塞满屏幕的翻译平台。它只是浮在当前网页上的两行字：上面放不懂的，下面给出答案。查完继续看，继续听，思路不用搬家。

## 它应该像什么

- 像字幕旁边的一张小纸条，而不是另一个世界。
- 两行就够：输入和输出。
- 不注册账号，不准备 API Key，不按次数收费。
- 翻译尽量留在设备里，文字不必绕服务器一圈。
- 能换语言、朗读、调颜色，但这些东西平时都安静地藏起来。

ENJIMO 使用 Chrome 内置的 `Translator API`。第一次使用某个语言组合时，Chrome 可能会下载语言包；之后由本地模型完成翻译。

## 让它出现

需要桌面版 Chrome 138 或更高版本。

1. 打开 `chrome://extensions`。
2. 开启右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择这个文件夹。
4. 刷新正在使用的普通网页。
5. 按 `Ctrl+Shift+9` 呼出或收起 ENJIMO。

也可以先选中网页里的文字，再右键选择“用 ENJIMO Translate 翻译”。

## 不用背说明书

输入停顿约半秒后会自动翻译，按 `Enter` 可以立即执行。译文右边的小像素扬声器负责朗读，再点一次停止。

左上角那个小方块是整套界面的秘密入口：

- 左键拖动它，ENJIMO 就跟着走。
- 右键点它，会出现一块很小的控制面板。
- 语言、配色、透明度、复制和尺寸都在那里，点按钮即可，不需要记快捷键。

语言面板支持中文、英文、西班牙语、日语和韩语。把语言方块拖进 `INPUT` 或 `OUTPUT`，方向就换好了。

调色盘没有说明文字。直接把喜欢的小色块拖到左上角方块、输入行或输出行，ENJIMO 会记住它。

## 如果你偏爱键盘

先按 `Ctrl+Shift+;`，松开后在 1.8 秒内按：

- `L`：语言
- `C`：配色
- `↑` / `↓`：透明度
- `V`：复制译文
- `S`：尺寸编辑
- `Esc`：取消或关闭

这些只是备用通道。右键左上角方块通常更轻松。

## 改完代码，立刻看一眼

双击 `启动 ENJIMO Translate.cmd`。

第一次需要在独立测试 Chrome 中开启开发者模式，并加载这个文件夹。之后每次双击都会重启测试窗口、读取最新代码并直接显示 ENJIMO，不会关闭日常使用的 Chrome。

正式版 Chrome 从 137 开始取消了命令行自动加载本地扩展，所以第一次手动加载无法省略；后面就不用反复折腾了。

## 它也有进不去的地方

普通网页以及网页容器实现的全屏通常可以显示 ENJIMO；原生视频全屏、`chrome://` 页面、Chrome 应用商店和浏览器之外的软件不允许普通扩展注入界面。

这是浏览器划下的边界。ENJIMO 的目标不是突破它，而是在允许出现的地方尽量少打扰你。
