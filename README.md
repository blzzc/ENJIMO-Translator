# ENJIMO Translate

一个基于 Chrome 本地 `Translator API` 的极简悬浮翻译扩展。

最初是为了在看番或上课时快速查询陌生词，不必退出当前网页再打开翻译网站。

## 功能

- 两行悬浮界面：输入与输出。
- 支持中文、英文、西班牙语、日语和韩语。
- 自动翻译与译文朗读。
- 自定义尺寸、透明度及三个界面区域的颜色。
- 设置自动保存，无需账号或 API Key。

## 安装

1. 使用桌面版 Chrome 138 或更高版本。
2. 打开 `chrome://extensions`，启用“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本项目文件夹。
4. 刷新网页。

## 使用

- 按 `Ctrl+Shift+9` 显示或隐藏翻译框。
- 输入停止约半秒后自动翻译，按 `Enter` 可立即翻译。
- 选中文字后，可使用右键菜单直接翻译。
- 点击译文右侧的像素扬声器可朗读或停止。
- 左键拖动左上角方块可移动界面。
- 右键左上角方块可打开功能面板。

语言通过拖拽语言块设置；颜色通过拖拽调色盘色块应用到拖拽方块、输入行或输出行。

## 开发预览

双击 `启动 ENJIMO Translate.cmd`。首次需要在独立测试 Chrome 中加载本项目，之后再次双击即可读取最新代码。

## 限制

支持普通网页及网页容器全屏。原生视频全屏、Chrome 内部页面、Chrome 应用商店和浏览器外的软件无法注入扩展界面。
