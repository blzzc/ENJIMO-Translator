新增 ENJIMO macOS 桌面版：截图识别日语，三行显示日语原文、罗马音和中文翻译。

- 沿用 ENJIMO 深色极简分行界面和青色拖动方块。
- ⌘⇧2 全局截图，⌘⇧9 显示 / 隐藏；菜单栏、Dock、Spotlight 均可打开。
- 支持粘贴截图、导入图片、修改原文、日语朗读和复制全部结果。
- 系统本地识别、词典读音、中文翻译，无 API Key；首次需下载语言包。
- 可调配色、透明度、字号和置顶；记住窗口位置与大小。

安装：下载 DMG，把 ENJIMO.app 拖进 Applications。

要求 macOS 15+。Universal 包含 Apple Silicon 和 Intel 架构。
当前为 ad-hoc 签名，未经过 Apple Developer ID 公证；首次被拦截时，可在「系统设置 → 隐私与安全性」选择「仍要打开」。不需要关闭系统安全功能。

自动测试覆盖日语读音、OCR、通用构建和应用启动。首次语言包下载、屏幕权限、实际全局截图需在本机完成验证。竖排文字及专有名词读音可能需要人工校对。

原 Chrome 扩展仍保留在仓库根目录。
